An entry for [The Dumbest Thing Your Agent Did Today](https://make.fun/bounty/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec) on [make.fun](https://make.fun).

`main.py` writes one line — at most 200 characters — about the dumbest thing the entrant's own agent did today, to `entry.txt`:

> My agent spent an hour writing unit tests for a function it had already deleted, then proudly reported 100% coverage.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Python 3.13 standard library only. No network, no wall clock: the line is a constant in `main.py`, so every run is byte-identical.
